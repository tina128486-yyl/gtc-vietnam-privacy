Personal Social Media Publishing Tool

This website provides information about a personal social media publishing setup used to organize and publish content to social media accounts authorized by the account owner.

Purpose

The tool uses Pendpost, an open-source social media publishing application, to help manage content and schedule posts for connected social media accounts.

Account Authorization

Social media accounts are connected only when the account owner authorizes access. The permissions granted determine which actions the tool can perform.
